Capabilities

Everything you need to type hands-free

Real-Time Transcription

Streams microphone input at 16kHz through Google's Web Speech API. 1.8-second audio windows with 0.6s overlap for continuous flow.

Smart Deduplication

difflib-powered sequence matching filters out repeated words, stutters, and false positives before injecting text — clean output every time.

Custom Hotkeys

Bind any keyboard shortcut to toggle voice recognition on or off. Record your combo with a single click in the settings panel.

Fine-Grained Control

Adjust typing speed, microphone sensitivity, auto-enter delay, and idle auto-stop to match your workflow and environment.

Auto-Enter

Configurable auto-submit presses Enter after a silence window — customizable from 3 seconds to 1 minute.

Zero-Setup Launch

Auto-installs all missing dependencies on first run — customtkinter, PyAudio, NumPy, SciPy, and more. Double-click VTT.pyw and go.

Architecture

How the engine works

Audio Capture

sounddevice streams microphone input at 16kHz into a ring buffer using PortAudio for low-latency signal acquisition.

Speech Recognition

SpeechRecognition sends 1.8-second audio windows to Google's Web Speech API. Multi-threaded to keep the UI responsive.

Type & Clean

PyAutoGUI injects deduplicated text as native keystrokes into the active application. Clean, fast, and seamless.

Get Started

Down and running in seconds

Requirements

Windows 10/11 · Python 3.10+ · A working microphone

# Clone and enter the directory
git clone https://github.com/jlaiii/VTT.git
cd VTT

# Run -- dependencies auto-install on first launch
python VTT.pyw

# Or double-click VTT.pyw for a silent launch

Tip: Double-click VTT.pyw to launch without a console window. The app runs as a compact floating overlay.
