Architecture

How each engine works

Google Engine

Mic → 16kHz stream → 1.8s windows (0.6s overlap) → Google STT API → dedup → type

Sliding-window approach for continuous real-time transcription. difflib sequence matching filters repeated words and stutters. Requires internet.

Whisper Engine

Mic → 16kHz stream → VAD detects speech → accumulates utterance → silence gap → faster-whisper transcribes → type

VAD-based utterance segmentation. faster-whisper with int8 quantization runs on CPU. Fully offline — zero data leaves your machine.

Get Started

Up and running in seconds

Option 1: One-Click (recommended)

Double-click start.bat — it finds Python, installs missing packages, and launches VTT automatically.

# Download or clone the repo, then double-click:
start.bat

First launch installs packages (~30s). Subsequent launches are instant (cached).

Option 2: Manual

Windows 10/11 · Python 3.10+ · A microphone

# Clone and enter the directory
git clone https://github.com/jlaiii/VTT.git
cd VTT

# Install required packages
pip install customtkinter SpeechRecognition PyAutoGUI sounddevice numpy scipy keyboard

# (Optional) For offline Whisper engine
pip install faster-whisper

# Launch (no console window)
pythonw VTT.pyw
