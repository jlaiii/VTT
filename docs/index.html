Get Started in 30 Seconds

Requirements

Windows 10/11 · Python 3.10+ · A working microphone

# 1. Clone and enter
git clone https://github.com/jlaiii/VTT.git
cd VTT

# 2. Install dependencies (or skip — VTT auto-installs)
pip install -r requirements.txt

# 3. Run!
python VTT.pyw

💡 Pro tip: Double-click VTT.pyw to launch silently — no console window appears.

How It Works

🎧

Audio Capture

Streams microphone input at 16kHz into a ring buffer using sounddevice/PortAudio.

🤖

Speech Recognition

Feeds 1.8-second audio windows to Google's Web Speech API with 0.6s overlap for continuous flow.

📝

Clean & Type

Deduplicates, formats, and injects text as native keystrokes via PyAutoGUI.
